# 架构总览

## 分层

```
┌──────────────────────────────────────────────────────────┐
│  接入层：CLI · REST API · Web 控制台 · Python/TS SDK      │
├──────────────────────────────────────────────────────────┤
│  编排层：长程智能体运行时 · 推理服务层 · 连续批处理调度    │
├──────────────────────────────────────────────────────────┤
│  算法层：MoE 路由 · W4A4 量化 · 视觉 RVQ · 分布式分片      │
├──────────────────────────────────────────────────────────┤
│  后端层：10 个 Provider 适配器（mock/vllm/sglang/...）     │
└──────────────────────────────────────────────────────────┘
```

## 设计原则

1. **内核零依赖**：`moe/quant/vision/agent/dist/engine` 只依赖 Python 标准库，保证离线可复现、可审计。
2. **算法与后端解耦**：算法层是「方法论」的参考实现；真正跑大模型交给 provider 后端（vLLM/SGLang 等）。
3. **可观测内建**：追踪、指标、回放、审计四件套，长程任务可溯源。
4. **规模可控**：从单卡 mock 到超节点多卡分片，同一套代码平滑扩展。
