# 命令行

```bash
longinfer doctor            # 自检

longinfer chat              # 交互对话
longinfer vision-tokenize   # 视觉离散化
longinfer quant             # 量化
longinfer agent-run         # 长程智能体
longinfer serve             # 控制面
longinfer benchmark         # 微基准
```
